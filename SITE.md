# Hero Rift — Site Oficial

Site oficial responsivo do Hero Rift, com visual dark fantasy.

## Conteúdo

- Apresentação cinematográfica
- Informações e recursos do jogo
- Classes: Bárbaro, Mago, Necromante e Arqueiro
- Progressão em cinco atos
- Ranking com pesquisa e filtro
- Download integrado ao servidor de atualizações
- Layout adaptado para PC e celular

## Publicar com GitHub Pages

Em **Settings → Pages**, selecione **Deploy from a branch**, escolha a branch **main** e a pasta **/(root)**.

O endereço ficará no formato:

`https://angeloslzxp-lab.github.io/hero-rift-updates/`

## Configuração

O arquivo `script.js` contém o endereço da API e o link de fallback para downloads.
